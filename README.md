# 🧭 Digital Wanderer

**Digital Wanderer** is an open directory and asset discovery tool designed to assist with lawful white-hat reconnaissance. It generates powerful search engine queries across categories like photos, videos, music, backups, NAS shares, and more — all from a beautiful and intuitive interface.

> ⚠️ This tool is intended strictly for educational and ethical use. Do not use it for unauthorized scanning or accessing content without permission.

## 🌟 Features

- Category-based query generation (Google Drive, Cameras, NAS, Music, etc.)
- Supports multiple search engines: Google, DuckDuckGo, Bing, Yandex
- Optional "Check if link is live" feature (HTTP status + page title)
- Clean, Bootstrap-powered UI
- Easily extensible with new categories or engines

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/YOUR_USERNAME/digital-wanderer.git
cd digital-wanderer
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the app
```bash
python app.py
```

Then open your browser and visit:  
📍 [http://127.0.0.1:5000](http://127.0.0.1:5000)
